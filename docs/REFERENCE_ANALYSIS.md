# TAP Academy reference analysis

Source: two desktop screen recordings (1920x1020), 5:58 and 3:24. Each was sampled every 8 seconds and key moments were inspected at full resolution. Very short transitions (< 8 s) could be missed.

## A. Confirmed in the videos

| Area | What is visible |
|---|---|
| Login | Split screen. Left: logo, "Login / Signup", mobile number with +91, "Continue with OTP", "or", "Login with email" (existing accounts only). Right: photo + headline. |
| Navigation | Slim icon rail (logo, notifications, QR code, MENU, Dashboard, Courses, Tests, Assignments, Company Questions, Jobs, Ask TAI, Profile), bookmarks, theme toggle (sun), avatar. Expanded drawer shows text labels, "Employability score", Light/Dark switch, user email. |
| Dashboard | Promo banner carousel; My Learning (progress bars for Courses / Assignments / Tests, Resume cards); Practice Streak (current streak, longest streak, total correct submissions, yearly green heatmap, "How we count" modal, LinkedIn share modal); Leaderboard (podium top 3 + ranked list, own row highlighted); Placement Drives (eligible / applied); Skills Acquired; Attendance table per subject and month (present / absent / week off). |
| Courses | Cards grid with All / In progress / Completed tabs and search. Course player: video, "Course content" panel with progress ring, lesson search, module accordion, durations, completion ticks, bookmark icon on lessons, page-based reading lessons. |
| Schedule | Month calendar of live classes with a "Filter by program" popover. |
| Tests | Tabs Upcoming / Contests / History, self-paced practice list, history cards with Result and Leaderboard links. Result page: score ring, marks scored, time taken, sections, per-question review (correct / your answer, explanation), Download report. |
| Assignments | Subject cards (modules, questions, marks, progress). Subject page: module list + question list with MCQ/Lab tag, Easy/Medium tag, marks, attempts, time spent, Review / Open editor, "Share achievement", "Practice again". |
| Lab IDE | Dark VS Code-style workspace: Instructions / Challenges / Discussions tabs, Problem Statement, Requirements, Run, Run Tests, terminal / editor / browser switcher, container start-up progress, checklist of test results. Labs shown were HTML/CSS web labs. |
| Company Questions | Company cards (tags per company), technology filter chips, All / In progress / Completed / Favourites. |
| Jobs | Drive list tabs (Technical, Non-technical, Shortlisted, Applied drives), drive details with eligibility check, apply panel with resume, hiring process, announcements. |
| Bookmarks | Questions / Jobs / Notes tabs. |
| Ask TAI | AI study chat with suggested prompts (query, concepts, quiz, aptitude, coding problem, SQL practice). |
| Profile | Banner + avatar, TAP ID, tabs Personal info / Education / Projects / Experiences / Certificates, resumes + "Generate resume", Save / Cancel. |
| Visual style | White cards on very light grey, thin borders, rounded corners (about 14px), Inter-like sans font, one strong blue accent, green heatmap, purple/blue progress segments, floating WhatsApp button. |

## B. NOT confirmed in the videos
* No algorithmic coding-problem page (problem statement + C/C++/Java/Python editor + visible and hidden test cases). The only code workspace shown is an HTML/CSS lab with checklist tests. The hidden-test-case judge is therefore an AVS addition, not a copy.
* Dark mode is only seen as a toggle, never rendered.
* Mobile layout is never shown (both recordings are desktop).
* Real loading / error messages are only seen as skeleton placeholders and a spinner.

## C. Added for AVS (not in TAP)
Email/password with admin approval, four roles, college-wide departments/years/sections, Asia/Kolkata streak rule (10 min), IST-based heatmap thresholds (1 / 2-4 / 5-9 / 10+), real code judge, XP/badges, placement prep modules.
